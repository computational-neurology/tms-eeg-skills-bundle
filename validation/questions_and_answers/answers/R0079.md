# Preprocessing active and sham TMS-EEG with different artifact profiles

## Short answer

Use one pipeline with one set of parameters for both conditions. Fix it before you look at the condition contrast. Wherever the method allows, estimate the data-driven cleaning operators (ICA unmixing, SSP-SIR or SOUND projectors, bad-channel sets) from **both conditions together**, then apply the **same operator** to active and sham. Do not tune cleaning to each condition's artifacts. If you clean each condition "optimally" for its own artifacts, the preprocessing becomes a hidden independent variable, and it can create or erase an active–sham difference. In practice:

- Make the parameters identical. A shared operator matters more than identical parameters, so use shared operators wherever you can.
- Do not remove sensory components.
- Equalise or report trial counts.
- Show with sensitivity analyses that the effect does not depend on the cleaning choices.

## Assumptions (please check)

- Within-subject design. Active and sham were recorded in the same session with the same cap, montage and amplifier settings.
- Active TMS shows the usual pulse/decay artifact and possibly TMS-evoked scalp muscle (stronger for lateral or frontal targets). Sham shows a different or smaller pulse artifact, little or no muscle, and an auditory/somatosensory response. A realistic sham may also add an electrical scalp-stimulation artifact.
- The aim is a TEP/GMFA/LMFP comparison between active and sham.
- If your sham is a tilted coil, a placebo coil, or a separate auditory or electrical control, the logic below still applies. Only the "worst-case artifact" in each step changes.

## Why this is a bias problem, not just a cleaning problem

1. **Condition-specific cleaning confounds the contrast.** Suppose active gets more ICA components removed, a longer interpolation window, or more SSP-SIR projections than sham. Then part of the active–sham difference is caused by the preprocessing. ICA-based cleaning shrinks TEP amplitudes across *all* peaks, not only near artifacts. Projection removes signal dimensions. So unequal cleaning can produce amplitude differences that look like a physiological effect.
2. **Under-cleaning is the mirror risk.** TMS-evoked muscle can survive ICA in a large share of participants, especially at prefrontal and premotor sites. Residual muscle that exists only in active will inflate early active-minus-sham differences.
3. **Sham is your sensory control, so do not clean that signal away.** Auditory and somatosensory responses are what sham is there to capture. If you remove "sensory" components from one or both conditions, you break the logic of the subtraction.
4. **Trial count and SNR bias amplitude measures.** GMFA and other rectified measures carry a positive noise bias. With fewer retained trials the noise floor rises. If you reject more active trials because of muscle, the active GMFA can be inflated or deflated relative to sham just from SNR.

## Recommended workflow

### 0. Pre-specify the pipeline
- Write down every artifact window, filter, threshold, the ICA rejection criteria, the SSP-SIR/SOUND parameters, the baseline window, the reference and the analysis windows before you examine the active-vs-sham contrast. Preregistration is ideal.
- If you can, make component and trial decisions blind to condition label. Code conditions as A/B, or review components on pooled data.

### 1. Load data and verify events for both conditions
- Check pulse timing in both conditions. Sham triggers may come from a different output or channel. Timing jitter that differs between conditions will smear one average more than the other.

### 2. Pulse artifact window: one window for both, set by the worst case
- Pick the interpolation or removal window from the condition with the longest artifact. That is usually active, unless a realistic sham with electrical stimulation has a longer transient. Apply the same window to both conditions, for example a placeholder `[-2, 10–12] ms`, confirmed on your data.
- Do not shorten the sham window "because sham is cleaner". If you do, early sham samples survive that are missing in active, and the early windows can no longer be compared.
- QC: overlay pre/post traces for both conditions, and compare residual pulse/decay between active and sham.
- Offline cleaning cannot recover every recharge, discharge or decay artifact. Any latency still contaminated in either condition should be left out of the analysis windows.

### 3. Bad channels: take the union
- Within each participant, mark a channel bad if it is bad in **either** condition, and handle it the same way in both. Exclude it from decomposition and repair it afterwards using the same method.
- Otherwise the two conditions end up with different channel sets, different interpolation, different rank and different topographies. That biases GMFA and LMFP directly.

### 4. Gross trial rejection: shared absolute criteria
- Use the same absolute thresholds, or thresholds computed on the **pooled** data. Do not use per-condition z-scores. Per-condition z-scores reject the same *proportion* of trials but hold the conditions to different *absolute* standards: active, being noisier overall, would be allowed more residual artifact.
- Log the number of rejected trials and the reasons, per condition.

### 5. ICA for ocular and non-stimulus-locked artifacts: fit jointly, apply identically
- Concatenate active and sham epochs from each participant (same session and montage), fit one ICA, and apply the same unmixing and the same rejected-component set to both conditions.
- Use this ICA pass only for blinks, eye movements and non-stimulus-locked/background muscle.
- **Do not** use ordinary ICA rejection to remove TMS-evoked muscle or clearly stimulus-locked components. They can contain or overlap with genuine TEP signal. In an active-vs-sham design such components exist almost only in active, so removing them is condition-specific cleaning by another route.
- **Do not** remove auditory/somatosensory-related components by default.
- If you filter a copy of the data to stabilise the ICA, keep that copy separate from the analysis data.
- QC: show topography, time course and spectrum for each removed component. For each condition, report the TEP before and after ICA and how much variance was removed. If removal changes active much more than sham, investigate before going further.

### 6. TMS-evoked muscle (mostly active): shared projection or a shared exclusion window
Choose one strategy and apply it to both conditions:

- **Option A: shared exclusion window.** Extend the interpolated or excluded window to cover the muscle burst in both conditions, and analyse only later windows (for example 20–60 ms onwards for DLPFC-type targets). Make no physiological claims inside the excluded interval.
- **Option B: SSP-SIR with a common projector.** Estimate the muscle subspace where the muscle actually is (active, or pooled data), then apply the **same** projector to sham. Both conditions then lose the same signal dimensions and keep the same rank. Starting values are about `pc = 2` and an artifact time range around `[5, 50] ms`. Check the components against muscle signatures: focal frontal/temporal topography, strong high-frequency power, and a brief biphasic time course.
- Avoid using SSP-SIR on active and not on sham, or different `pc` values per condition.
- Too strong regularisation or projection can turn residual artifact into structure that looks like a TEP. Run the sensitivity checks in step 11.

### 7. SOUND or other denoising
- Use the same regularisation (for example `lambda`) and the same number of iterations for both conditions. Run it on pooled data or with identical settings.

### 8. Filtering, downsampling, baseline, reference
- Use the same filters, applied late, after the TMS-specific cleaning. Avoid an early high-pass on short epochs.
- Use the same downsampling, done after pulse and timing QC.
- Use the same baseline window, for example `[-500, -50] ms`, and confirm it is clean in **both** conditions.
- Use the same full-channel reference (for example the average reference) at the same stage. Select LMFP ROI channels only after referencing, and use the same ROI for both conditions.

### 9. Final trial rejection and trial-count matching
- Apply the same criteria to both conditions.
- For each participant, match the number of retained trials across conditions. Randomly subsample the larger condition, ideally repeating this many times and averaging. If you do not match, report the imbalance and show that the result holds after matching.
- Report retained trials per condition and per participant.

### 10. Rank
- After every rank-reducing step (interpolation, ICA, SSP-SIR, SOUND), report the retained rank and confirm it is the **same** in active and sham. Different rank changes channel covariance and topography, and therefore GMFA.

### 11. Sensitivity and bias checks
- **Pipeline robustness:** rerun the main contrast with plausible variants. Examples: no ICA vs ICA; SSP-SIR `pc` = 1/2/3; a shorter vs longer interpolation window. An effect that appears in only one variant is not robust.
- **Cleaning-asymmetry check:** for each condition, compare the change from raw to cleaned data (RMS, variance removed, change in topography). If the cleaning removes much more from active, say so and interpret early windows cautiously.
- **Residual-muscle subgroup check:** split participants by whether muscle is visible in the *uncleaned* active 5–15 ms window. Compare cleaned active-minus-sham TEPs and spatial correlations between the subgroups. If they diverge, the cleaning is not doing what it claims. Repeat the main analysis in the no-muscle subgroup.
- **Residual pulse/decay in sham:** check that sham is not left with its own artifact (for example from electrical stimulation) that would be read as "cortical" after subtraction.

## Interpreting the contrast

- **Sensory inputs.** Late components (roughly 60 ms onwards, especially N100/P200) are strongly shaped by click sound and, to a lesser degree, scalp twitch. Active and sham can be perceptually indistinguishable and still differ neurally: N45, N100 and P180 were larger for active than for realistic sham despite masking. So perceptual matching does not prove the sensory confound is matched.
- **Sensory ratings.** Collect separate ratings for loudness, scalp twitch, discomfort and pain in each condition. Use them as covariates or matching checks. Pain ratings do not track sensory contamination of TEPs.
- **Sham subtraction.** Subtracting a well-matched sham is a reasonable way to remove peripherally evoked potentials. Evidence from M1 and SMA, within about 110 ms, suggests sensory input adds to the TEP rather than interacting with it. Do not extend that result beyond the tested targets and window, and do not treat sham-subtracted TEPs as pure cortical activity.
- **Early windows.** Early windows are more likely to reflect the stimulated cortex, but they are not automatically clean. Check residual muscle separately (step 11).
- **What TEPs measure.** TEP, GMFA and LMFP differences are scalp-level responses. They are shaped by cortical, network, sensory, muscle and preprocessing factors, so do not describe them as pure excitability measures.

## What to report

- Every parameter, per condition, stated as identical. Any unavoidable deviation should be stated and justified.
- The pulse interpolation window and the latencies excluded from analysis.
- The bad-channel union, the interpolation method, and the retained rank after each step.
- ICA: the fitting data (pooled), the rejection criteria, and the topography, time course and spectrum of removed components. Give variance removed per condition, not just component counts. The raw number of removed components is not a quality metric.
- SSP-SIR/SOUND: the parameters, the projector source, and evidence that the same operator was applied to both conditions.
- Retained and matched trial counts per condition.
- The results of the sensitivity analyses, and the sensory ratings per condition.

## Minimal pseudocode outline

```text
for each participant:
    load active + sham (same montage); verify triggers in both
    interpolate pulse with ONE window = worst-case condition
    bad_chs = union(bad_active, bad_sham)
    gross trial rejection with pooled/absolute thresholds
    epochs_all = concatenate(active, sham)         # keep condition labels
    ica = fit_ICA(epochs_all, exclude=bad_chs)     # ocular / non-stimulus-locked only
    apply same ica.exclude to active and sham
    muscle: shared exclusion window OR one SSP-SIR projector applied to both
    same filters, baseline, reference, ROI
    final rejection (same criteria) -> equalise trial counts (repeat random subsampling)
    log rank, trials, variance removed per condition
group level: active vs sham (and sham-subtracted) with pre-specified windows,
             sensory ratings as covariates, sensitivity re-runs
```

This outline is not runnable code. The function names are placeholders, and the exact library calls (for example in MNE-Python or TESA) should be checked against the current documentation of whichever toolbox you use.
