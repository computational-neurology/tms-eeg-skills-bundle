# Preprocessing active and sham TMS-EEG without biasing the comparison

## Core principle

**Both conditions go through one pipeline: the same steps, parameters, decision rules and spatial filters, applied without knowing which condition is which.** Different artifact profiles are expected. Active TMS produces a large pulse artifact, a decay/electrode-polarisation artifact, TMS-evoked cranial muscle activity and recharge artifacts. Sham produces little or none of these, but it still gives the click and possibly scalp sensation. The risk is not only running *different pipelines*. A subtler risk is running the *same pipeline with condition-specific, data-driven fits*: separate ICA decompositions, separate component selection, separate SSP projectors or different rejection rates. Any of these can create, remove or change an active–sham difference.

Assumptions: within-subject design; active and sham recorded in the same session or sessions with the same cap and montage; sham markers exist at the same timing as active pulses; the goal is an active-vs-sham contrast of TEPs (or derived measures) after the first ~15–20 ms.

---

## 1. Acquisition and bookkeeping (before preprocessing)

- Randomise or interleave active and sham blocks so drift, fatigue, gel drying and impedance changes don't line up with condition.
- Make sure sham has event markers with identical timing (including ISI jitter), so epochs can be defined the same way.
- Record perceived loudness, scalp sensation and discomfort ratings per condition. You will need these to interpret any residual difference (see §6).
- Before preprocessing, replace condition labels with neutral codes (e.g. "A/B") for every step that involves human judgement.

## 2. Pulse-locked steps: use the union of what each condition needs

| Step | Rule |
|---|---|
| Pulse removal / interpolation window | Choose the window the **active** condition needs (e.g. −2 to +10–15 ms) and remove/interpolate **the same window in sham**, even if sham is clean there. |
| Recharge artifact | If it is removed in active, remove the same window in sham (sham coils may also produce one). |
| Epoch length, baseline window | Identical. |
| Down-sampling, filters | Identical. Apply filters **after** the pulse window has been removed/interpolated, so ringing from the large active artifact doesn't spread into the data. |
| Analysis window | Limit inference to latencies where the active data are credibly clean in every participant. Don't interpret early components in sham that you cannot see in active. |

## 3. Channels and trials

- **Bad channels:** take the *union* of bad channels across both conditions for each participant and remove/interpolate them in both. This keeps rank, spatial sampling and the average reference identical.
- **Trial rejection:** use the same objective thresholds (amplitude, kurtosis, joint probability) for both conditions. Active will usually lose more trials because of muscle and decay. Report rejection counts per condition and test whether they differ.
- **Trial-count matching:** evoked SNR, and therefore residual noise, depends on trial count. Randomly subsample the condition with more trials to match the other within each participant. Ideally repeat the subsampling (e.g. 100–1000 times) and average the results or check how stable they are.
- **Re-referencing:** use the same reference, computed after the same channel set has been restored in both conditions.

## 4. Data-driven artifact removal (the main source of bias)

### Preferred: fit once, apply to both
1. Run the identical earlier steps on both conditions.
2. **Concatenate** active and sham epochs for each participant (after trial-count matching, or with balanced numbers so neither condition dominates the fit).
3. Run **one ICA decomposition**, or estimate one SSP-SIR artifact subspace, on the combined data.
4. Choose components/projectors using **pre-specified, automated criteria** (e.g. TESA-style component classification, ICLabel thresholds, or time-course/topography rules), blind to condition.
5. Apply the **same unmixing matrix and the same removal** to both conditions.

Why this works: components that capture active-only artifacts (decay, cranial muscle) carry almost no variance in sham, so removing them there does little. More importantly, any brain signal lost through imperfect separation is lost *equally* in both conditions, so the contrast is not distorted by asymmetric cleaning.

### Specific methods
- **Two-round ICA (TESA-style):** the first round targets the large early muscle/decay artifact. Run it on the concatenated data and remove the same components from both conditions. Don't skip the first round for sham just because sham "doesn't need it".
- **SSP-SIR:** estimate the artifact subspace from the early post-pulse window. That subspace comes mostly from active data, so either estimate it on the concatenated data or from active alone, then apply **the same projector and SIR reconstruction to sham**. SIR changes topographies, so applying it to only one condition would create a difference by itself.
- **Decay-artifact fitting (exponential/polynomial):** fitting per trial is fine because it models a physical artifact. Use the same model and fitting window in both conditions, and check that the sham fits are near zero rather than absorbing real neural signal.
- **SOUND or other noise-suppression methods:** use the same settings, and preferably a noise estimate pooled across conditions.

### If separate decompositions can't be avoided
For example, when conditions were recorded in different sessions: use identical automated selection criteria, report how many components and how much variance were removed per condition, test for differences, and treat this as a limitation backed by sensitivity analyses (§7).

## 5. Don't remove sensory responses as "artifact" in only one condition

Sham exists to capture the auditory and somatosensory evoked potentials (N100/P180-like responses, sensory components). **Don't** remove "auditory/sensory" ICA components selectively in active. Either keep them in both conditions, which is the usual choice because the active–sham contrast is what separates them, or remove them by an identical rule applied to the joint decomposition. Removing late, broadly central components only in active is a common way to erase or invent a "transcranial" effect.

## 6. Check whether the sham actually matches the peripheral input

Very different artifact profiles may mean the sham does not reproduce the somatosensory input. A tilted coil or a sham coil without electrical scalp stimulation produces little scalp sensation or muscle twitch. In that case, active-minus-sham differences in the 50–250 ms range may reflect sensory input rather than cortical response.
- Compare perceived intensity ratings between conditions.
- Compare the late, central components that should be sensory. If sham is much smaller there, say so.
- In future studies, consider a realistic sham with electrical scalp stimulation, plus noise masking and foam spacing in both conditions.

## 7. Prove the pipeline is not driving the result

- **Quality metrics per condition:** retained trials, interpolated channels, components removed, variance removed, residual early artifact amplitude, post-cleaning baseline noise. Report them, and consider including significant differences as covariates.
- **Multiverse / sensitivity analysis:** run 2–3 established, defensible pipelines (e.g. TESA two-round ICA, SSP-SIR based, minimal cleaning with a later window). Report whether the active–sham effect survives each. Comparisons of TMS-EEG pipelines show that the choice of pipeline substantially changes TEPs.
- **Ground-truth checks:**
  - *Signal preservation:* add a known synthetic TEP (or the grand-average sham response) to sham trials, run the full pipeline, and measure how much is recovered.
  - *Artifact leakage:* add active-like artifact templates (decay, muscle bursts) to sham data and check that the pipeline removes them without leaving a spurious "effect".
- **Visual QC, blind:** inspect butterfly plots, GMFP and topographies for both conditions under coded labels before unblinding.

## 8. Statistics

- Pre-register the analysis window, regions of interest/electrodes, and test (e.g. a cluster-based permutation test on active vs sham across time × channels, or GMFP/ROI-based measures in predefined windows).
- Analyse within subjects, with the same window for both conditions. Exclude latencies covered by interpolation.
- Report effects together with the preprocessing quality metrics, so readers can judge whether differences are cortical or residual artifact.

---

## Minimal checklist

1. Labels blinded; identical markers and epochs.
2. Same pulse interpolation window, chosen by active's needs.
3. Union of bad channels; same reference.
4. Same rejection thresholds; trial counts matched.
5. ICA/SSP-SIR fitted **jointly** on concatenated data; same components and projectors removed from both.
6. Sensory components treated the same way in both conditions (preferably retained).
7. Quality metrics reported and compared; multiverse and simulation checks done.
8. Sham adequacy (somatosensory/auditory matching) discussed as a limit on interpretation.

**Key references:** Rogasch et al. 2017 (TESA); Mutanen et al. 2016 (SSP-SIR) and 2018 (SOUND); Conde et al. 2019 and Rocchi et al. 2021 (peripheral contributions to TEPs and realistic sham); Bertazzoli et al. 2021 (variability across pipelines); Belardinelli et al. 2019 and Hernandez-Pavon et al. 2023 (TMS-EEG reporting and methodological recommendations).
