# Preprocessing active and sham TMS-EEG without biasing the comparison

## Short answer

Use **one preprocessing pipeline, fixed in advance and applied identically to both conditions**. When the conditions carry different artifacts, the pipeline has to be built for the worse one. Then apply that same pipeline, with the same parameters, the same spatial filters and the same retained rank, to both conditions. Do not tune cleaning separately for active and sham. Condition-specific cleaning is a hidden confound in an active-vs-sham contrast: any difference it produces will look like a TMS effect.

Treat the artifact differences themselves as something you measure and report. Then restrict your conclusions to the latencies where both conditions are demonstrably clean.

## Assumptions

You did not give these details, so I assumed:

- Within-subject design, with active and sham recorded in the same session and with the same montage.
- Sham is a sham coil, a tilted coil, or a "realistic" sham, possibly with electrical scalp stimulation.
- The goal is TEP/GMFA/LMFP comparison.
- Active shows stronger pulse/decay and TMS-evoked scalp-muscle artifact. Sham shows less of these, but it may have its own artifact, for example from electrical scalp stimulation or a different coil.

Adjust the steps if your situation differs.

---

## 1. Fix the pipeline before you look at condition differences

Write down every parameter before inspecting condition-wise TEPs, and preregister it if you can:

| Step | What must be identical across conditions |
|---|---|
| Pulse window removal/interpolation | One window, sized to cover the **longest** artifact in either condition, e.g. `[-2, 10]` or `[-2, 12] ms`. Widen it further only after checking. |
| Decay/recharge handling | Same method and parameters, e.g. the same ICA pass or the same detrending model |
| Bad-channel policy | Use the **union** of bad channels across conditions for each participant, so both conditions are interpolated and lose rank in the same way |
| Filters | Same high-pass, low-pass and notch settings, applied at the same stage, i.e. late, after TMS-specific cleaning |
| Epoch and baseline | Same windows. Check that the baseline (e.g. `[-500, -50] ms`) is clean in **both** conditions. |
| Component cleaning (ICA/SOUND/SSP-SIR) | Same criteria, same component or projection count, same retained rank |
| Trial rejection | Same thresholds, which are absolute or derived from pooled data, not per condition |
| Reference | Same final full-channel reference (e.g. average), applied at the same stage |

A practical rule: if the active condition needs a longer interpolation window, apply that longer window to sham as well. Do not keep the extra early samples in sham just because they happen to be clean there. Otherwise the two conditions are no longer measuring the same interval.

## 2. Use shared spatial filters: decompose jointly and apply identically

This is the main way bias gets in. If you fit ICA, SSP-SIR or SOUND separately on each condition, the components differ, so you remove different things from each condition.

- **Fit decompositions on the concatenated active + sham epochs for each participant.** Then apply the **same** unmixing or projection operator to both conditions.
- If an artifact subspace can only be estimated from active trials (e.g. SSP-SIR estimating TMS-evoked muscle in a `[5, 50] ms` window), **apply the same projection to sham too**. Removing a dimension from active only changes the spatial structure, and so the GMFA, of only one condition.
- Report the retained rank after every rank-reducing step. Make sure it is **equal** across conditions.

## 3. Be careful which components you remove

- Use ICA only for ocular, blink, and non-stimulus-locked/background muscle artifacts. **Do not remove TMS-evoked muscle or clearly stimulus-locked components with ordinary ICA rejection.** Real TEP signal is also time-locked to the pulse, and active has more of both.
- **Do not remove auditory/somatosensory-related components by default.** These are exactly the contributions that sham is there to capture and subtract. If you remove them unevenly, the logic of the sham control breaks.
- Decide on components **blind to condition**: use a decomposition on pooled data, pre-specified criteria (topography, time course, spectrum), or automated suggestions verified by a rater who does not know the labels.
- The number of rejected components is not a quality metric. Show the time course, topography and spectrum of every rejected component, so readers can see the components are non-neural.

## 4. Handle TMS-evoked muscle in active without creating an asymmetry

Active stimulation will usually carry scalp-muscle artifact that sham lacks, and it can exceed 1 mV for frontal/lateral targets. Options, in order of preference:

1. **Reduce it at acquisition**: adjust the coil position or orientation. Afterwards nothing can fully recover the masked early signal.
2. **Projection (SSP-SIR)** with a fixed `pc` (start at 2), estimated from pooled or active data and **applied to both conditions**.
3. **Define a shared exclusion window.** If the muscle burst forces interpolation up to about 10–15 ms in active, the same interval is excluded from the analysis in both conditions, and you make no claims about it.

Check whether cleaning worked. Before cleaning, mark participants with visible muscle activity in the uncleaned 5–15 ms epochs. After cleaning, compare their condition effects with those of participants without muscle activity. If the active-minus-sham effect is carried mainly by the muscle subgroup, the "effect" is probably residual artifact.

## 5. Balance trials

- Trial rejection usually removes more active trials, because active trials have more artifact.
- **Equalise trial counts across conditions**, e.g. by randomly subsampling the condition with more trials, ideally repeated over many random draws. Averaged-trial count changes SNR, and with it TEP/GMFA amplitude, especially the noise floor of GMFA.
- Report retained trials per condition and per participant, plus the rejection reasons.

## 6. Restrict the analysis window to latencies that are clean in both conditions

- Run a per-condition artifact QC: pulse residuals, decay, early high-frequency bursts, butterfly plots at 0–100 ms.
- Base condition comparisons only on time windows where **both** conditions pass QC. Excised or interpolated samples are not physiological signal in either condition.
- Report early (<~20 ms) differences only if residual pulse/muscle artifact has been ruled out in both conditions. Otherwise, start inference at a defensible later latency, e.g. 20–60 ms for frontal targets.

## 7. Run sensitivity analyses (pre-specified)

Show that the active-vs-sham result is not produced by the pipeline:

- Vary the pulse window (e.g. `[-2, 10]` vs `[-2, 15] ms`).
- Vary the SSP-SIR `pc` (1/2/3) or the number of rejected ICA components.
- Compare an ICA-light branch with an ICA-based branch. ICA-based cleaning tends to shrink TEP amplitudes at all peaks, so it can reduce real differences as well as artifact.
- Re-run with trial counts equalised and not equalised.

If the effect changes direction or disappears across reasonable choices, report it as fragile.

## 8. Interpret the contrast correctly

- **Sham subtraction is only as good as the sham match.** With well-matched sham (saturated or individually matched peripheral evoked potentials), recent evidence suggests sensory inputs mostly *add to* rather than *interact with* the cortical TEP within roughly the first ~110 ms (tested at M1 and SMA). That supports subtraction there, but the result should not be extended to other windows or targets.
- **Perceptual matching does not mean neural matching.** In one study, N45, N100 and P180 were still larger for 90% RMT active than for a sham participants could not tell apart, even with masking and ICA. No pipeline fully removes sensory contributions.
- Components after ~60 ms (N100/P200) are strongly shaped by click loudness and, to a lesser extent, by scalp twitch. Collect **separate ratings of sound, twitch, discomfort and pain** for each condition. Use them as covariates or report them. Pain ratings are not a good proxy for sensory contamination.
- Do not present active-minus-sham differences as a pure measure of cortical excitability.

## Minimal workflow template (Python/MNE-style pseudocode)

Placeholders are in `<>`. Check the exact function signatures against your installed MNE/TESA/tmseegpy version.

```python
# 1. Load both conditions per participant with identical settings
raw_active, raw_sham = load(<active_file>), load(<sham_file>)

# 2. Same pulse window for both, sized to the worst condition
PULSE_WIN = (<-0.002>, <0.012>)          # seconds; fixed a priori
for raw in (raw_active, raw_sham):
    interpolate_pulse(raw, events=<tms_events>, window=PULSE_WIN)

# 3. Union of bad channels across conditions
bads = sorted(set(raw_active.info["bads"]) | set(raw_sham.info["bads"]))
raw_active.info["bads"] = raw_sham.info["bads"] = bads

# 4. Epoch with identical windows/baseline
ep_a = mne.Epochs(raw_active, ev_a, tmin=<-1.0>, tmax=<1.0>, baseline=<(-0.5, -0.05)>, preload=True)
ep_s = mne.Epochs(raw_sham,   ev_s, tmin=<-1.0>, tmax=<1.0>, baseline=<(-0.5, -0.05)>, preload=True)

# 5. Fit ONE decomposition on pooled epochs, apply the same solution to both
pooled = mne.concatenate_epochs([ep_a.copy(), ep_s.copy()])
ica = mne.preprocessing.ICA(n_components=<n>, method=<"fastica">, random_state=<seed>)
ica.fit(<ica_training_copy_of(pooled)>)  # separate filtered copy if needed
ica.exclude = <ocular_and_non_stimulus_locked_only>   # chosen blind to condition
ica.apply(ep_a); ica.apply(ep_s)

# 6. If SSP-SIR/SOUND is used: same parameters (pc, time_range, lambda) and same
#    projector applied to both conditions; log retained rank for each.

# 7. Same rejection thresholds, then equalise trial counts
reject = <dict(eeg=...)>                 # absolute, pre-specified
ep_a.drop_bad(reject); ep_s.drop_bad(reject)
# subsample to equal n (repeat over random draws for robustness)

# 8. Same late filtering, same reference, then TEP/GMFA/LMFP
for ep in (ep_a, ep_s):
    ep.filter(<l_freq>, <h_freq>); ep.set_eeg_reference("average")
```

## QC checklist to report

- Pulse window and interpolation, with before/after overlays **for each condition**.
- Bad-channel union per participant and the repair method.
- Decomposition fitted on pooled data. Rejected components with topography, time course and spectrum. Raters blind to condition.
- Retained rank after each rank-reducing step, **equal across conditions**.
- Retained trials per condition (before and after equalisation) and rejection reasons.
- Baseline window checked for residual artifact in both conditions.
- Per-condition artifact profile (pulse residual, decay, 5–15 ms muscle), reported as a result.
- The analysis window restricted to latencies clean in both conditions.
- Sensitivity analyses across window length, projection/component count, and ICA-light vs ICA-based cleaning.
- Sensory ratings (sound, twitch, discomfort, pain) per condition, and the sham type and how it was matched.

## Key caveats

- Identical processing removes **processing-induced** bias. It does not remove artifact differences that are present in the data. Residual active-only muscle or decay can still produce an apparent "effect", so the clean-window restriction and the muscle-subgroup check are essential.
- Heavy cleaning can hide a real effect, and light cleaning can leave artifact that looks like one. Report both branches if they disagree.
- A sham-subtracted TEP is not automatically pure cortical activity. How far it can be trusted depends on how well the sham matches the sensory input of active TMS.
