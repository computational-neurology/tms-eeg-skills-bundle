# PCIst = 0.25 in a sedated patient: is it below the consciousness threshold?

## Short answer

**No, you can't draw that conclusion from this comparison.** The 0.31 cutoff (PCI\*) belongs to a different metric, the original **PCI-LZ** (Casali et al., 2013). It does not apply to **PCIst** (Comolatti et al., 2019). The two indices use different algorithms and different scales, and they have different cutoffs. Comparing 0.25 with 0.31 tells you nothing about this patient.

Also, a PCIst of 0.25 is not a "low but plausible" value. It is so far below the published PCIst range that you should check the computation before interpreting it at all.

## Why 0.31 does not apply

| | PCI-LZ (Casali 2013) | PCIst (Comolatti 2019) |
|---|---|---|
| Computed on | Estimated cortical sources (needs forward/inverse modelling) | Sensor-space TEP (no source model) |
| Core operation | Binarise against baseline statistics, then Lempel-Ziv compression | SVD, then counting recurrence-based state transitions |
| Range | Normalised, bounded at 1 | **Not upper-bounded** |
| Typical values | 0–1; e.g. MCS patients with PCImax of 0.34 and 0.40 | Wakefulness **47.89 ± 12.65**; NREM sleep/anaesthesia **14.19 ± 5.26** (382 sessions, 108 healthy subjects) |
| Cutoff | PCI\* = 0.31 | Derived empirically from data, **separately for each montage**; not 0.31 |

The two metrics correlate (r = 0.82) and classify consciousness about equally well (AUC 0.995 vs 0.998), but their numbers can't be swapped. On the PCIst scale, 0.31 has no meaning.

## Why 0.25 is a red flag

The PCIst benchmark for unconscious states (NREM sleep, propofol, midazolam, xenon) averages about **14**. A value of 0.25 sits roughly 50 times below the typical unconscious value. Even deep sedation would not normally give that. A number this small usually means one of these:

1. **It is actually a PCI-LZ value**, or a PCIst value that some step has rescaled or normalised to look like PCI-LZ. Check what your code returns. If it really was PCI-LZ computed with source reconstruction, then 0.31 is the right reference (see the caveats below).
2. **Wrong parameters or units.** `times` must be in **milliseconds** with negative baseline values, and the windows must use the same units. The published TMS-EEG settings are `baseline_window = (-400, -50)`, `response_window = (0, 300)`, `k = 1.2`, `min_snr = 1.1`, `max_var = 99`, `embed = False`, `n_steps = 100`. Times in seconds, or a very short response window, can shrink the result to almost nothing.
3. **Wrong input.** The function expects a **trial-averaged** (channels × time) array, not single epochs.
4. **Almost no signal survived dimensionality reduction.** If only one weak component passes the SNR filter, PCIst falls close to zero. This happens when:
   - stimulation failed (no clear early TEP), or
   - there were too few trials, or
   - ICA removed too much of the response.
5. **NaN handling.** If the input contains NaN, the reference implementation returns exactly 0. A value of 0.25 is not that, but if your pipeline averages across sites or sessions, check that none of them was a silent zero.

### Diagnostic step: decompose the value

Run the computation with the full output enabled (`full_return=True`) and look at three things:

- **Number of surviving components (N_C):** the length of `dNST`, or the count of entries in `snrs` above `min_snr`.
- **Per-component transitions:** the values in `dNST`.
- **Explained variance:** `var_exp`.

The index is a product, **PCIst = N_C × mean(ΔNST)**, so it falls when either factor falls:

- **Several components but almost no transitions** would fit a stereotyped, bistable response, i.e. genuine low complexity.
- **One or zero components** points to a weak or absent response, i.e. acquisition or processing failure.

Report this decomposition, not just the single number.

## Before reading any physiology into it

A low PCI is weak evidence on its own, because acquisition failure and genuine loss of complexity produce the same scalar. Rule out the technical explanations first:

- **Was there a real response?** Check for a peak-to-peak TEP above about **10 µV in the first 50 ms** at the channel nearest the target (average of about 20 trials).
- **Trial count:** about **120–150 trials per site**. This matters most in sedation, where large slow waves dominate the ongoing EEG.
- **Target placement:** away from structural lesions, and away from lateral scalp muscle.
- **Over-cleaning:** compare the TEP before and after ICA. Global loss of amplitude suggests the response itself was removed.
- **Arousal and sedation level** during recording, and which drug was used.

## Interpretation caveats, even once the value is valid

- **Use a montage-specific PCIst cutoff.** You need the threshold derived for a 60-channel hd-EEG montage, and your preprocessing must be comparable to the pipeline that cutoff came from. The benchmark pipeline was:
  - about 200 pulses per session
  - ICA
  - 0.1–45 Hz band-pass filter
  - downsampling to 725 Hz
  - average reference
  - baseline −400 to −5 ms

  Do not borrow a cutoff from another montage, amplifier or cleaning pipeline without re-deriving it. If your pipeline differs a lot, compare values within your own dataset rather than against an absolute threshold.
- **Use PCImax across at least two stimulation sites.** One site that gives a low value does not show that the patient's capacity is low; that site may simply not have responded.
- **Sedation is itself a low-PCI state.** Propofol and midazolam both lower PCI, so a below-threshold value under sedation is expected. It says little about what the patient's capacity for consciousness would be off sedation. Ketamine is an exception: it typically keeps PCI high.
- **PCI detects capacity; it is not a graded scale.** It does not track behavioural severity (no correlation with CRS-R) and cannot separate MCS+ from MCS−. A single value near any cutoff should not be read as "how conscious" the patient is.
- **Report fully:** which metric, all parameters, montage, trial count, number of sites, where the cutoff came from, and the N_C / mean(ΔNST) decomposition.

## Assumptions

- "PCIst" means the state-transition index of Comolatti et al. (2019), computed in sensor space with the reference implementation.
- The 0.25 comes from a single session, possibly a single stimulation site.
- Sedation type and depth were not stated.

**Bottom line:** do not classify this patient against 0.31. First confirm which metric you computed and verify the computation. Then compare PCImax over at least two sites with a cutoff derived for your 60-channel montage and pipeline, keeping in mind that sedation itself lowers PCI.
