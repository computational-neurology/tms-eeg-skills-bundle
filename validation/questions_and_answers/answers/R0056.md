# Preprocessing active and sham TMS-EEG without biasing the comparison

## Assumptions

- Within-subject design. Active and sham blocks were recorded in the same session with the same cap. If they were recorded on different days, see the note in section 3.
- "Different artifact profiles" means that active TMS has a large pulse or decay artifact and TMS-evoked cranial muscle activity, and sham has smaller or different artifacts. Sham artifacts depend on the method: a sham coil or tilted coil gives a weaker pulse artifact, and realistic sham with electrical scalp stimulation adds its own electrical artifact.
- You mainly want to compare TEP amplitudes, topographies or GMFP between conditions, and possibly oscillatory responses.

## The core problem

There are two opposite ways to bias the comparison:

1. **Condition-specific cleaning.** You clean each condition "as much as it needs", for example by removing 12 ICA components from active and 3 from sham. Each removal also takes out some neural and sensory signal and changes the spatial rank of the data. The active–sham difference then partly reflects how much cleaning each condition got.
2. **Naive identical cleaning.** You run the same pipeline, but its data-driven steps (ICA, trial rejection, bad channels) end up making different decisions per condition. The result is either residual artifact in active only, or over-cleaning of active only.

The goal is to make the **procedure, parameters and decision rules** identical. Wherever possible, the **actual transformation** (the projector or the removed components) should also be identical. Then you measure what was removed in each condition and report it.

## Recommended strategy

### 1. Freeze the pipeline before looking at condition differences

- Write down every step, parameter, threshold and analysis window in advance, ideally in a preregistration.
- Decide all parameters on pooled data or on pilot data, never on the contrast.
- For any manual step, such as ICA component review, blind the reviewer to condition: recode file names and remove event labels. Fully automated classification with fixed thresholds is better still. An example is the TESA component-selection criteria with fixed thresholds.

### 2. Use the worst-case condition to set time windows, then apply them to both

- **Pulse artifact removal or interpolation:** use the same window in both conditions, for example −2 to +10/15 ms. Set it from the active condition, where the artifact lasts longest. A shorter window in sham means more early data survives in sham, and that difference becomes a confound.
- **Interpolation method:** use the same method (cubic or linear), the same fit windows, and the same handling of the recharge artifact.
- **Baseline and order of operations:** use the same baseline window, the same epoch limits and the same order of operations. Remove or interpolate the artifact before any filtering, so the filter does not smear it into the baseline.
- **Early latencies:** state explicitly that the early window, before about 15–20 ms, cannot be interpreted when there is strong muscle artifact. Exclude it from statistics in both conditions, not only in active.

### 3. Share the spatial filters across conditions

This is the most important step.

- **ICA, PCA or SOUND:** concatenate active and sham epochs within each subject (after the shared pulse-removal step) and run one decomposition. Components that capture muscle or decay artifact are then removed from both conditions with the same unmixing matrix. If the artifact exists only in active, the component simply carries almost no variance in sham. Both conditions lose the same spatial subspace, so topographies and rank stay comparable.
  - Caveat: very large active artifacts can dominate the decomposition. The usual fix is a two-step approach, with an identical first step for both conditions. First run an early round of ICA or PCA targeted at the large TMS-evoked muscle and decay components. Then run the main ICA on the combined data.
  - If conditions were recorded in different sessions (re-capped), shared decomposition does not make sense. In that case, run separate decompositions with identical automated criteria and quantify the differences (see section 5).
- **SSP-SIR (projection-based muscle-artifact suppression):** estimate the artifact subspace from the active data, where the muscle artifact is present. Then apply the same projector, and the same SIR lead-field correction, to the sham data too. SSP-SIR inevitably distorts the signal, and applying one projector to both conditions makes the distortion identical.
- **Bad channels:** interpolate the union of bad channels from both conditions in both conditions. Do this before re-referencing to the average.

### 4. Don't use preprocessing to remove sensory responses

Removing auditory and somatosensory evoked potentials with ICA, especially in one condition only, breaks the logic of the comparison. Those responses are what the sham is supposed to model, and they are not spatially separable from TEPs in a reliable way.

- Handle peripheral confounds through the design: noise masking, a foam layer, and a realistic sham that matches perceived loudness and scalp sensation.
- Check matching with perceptual ratings after each block.
- Treat the active–sham contrast as the estimate of the transcranial effect, and only to the extent that sensory matching was achieved. Report the ratings.

### 5. Equalize data quality and quantify what was removed

**Trial and channel rejection**

- Use identical rejection thresholds in both conditions.
- After rejection, randomly subsample trials so that trial counts are equal per subject and condition. Repeat the subsampling several times, or use a fixed seed.
- This matters because GMFP, rectified measures and peak amplitudes are biased upward by noise, so unequal trial numbers alone can create "differences".

**Report per condition**

- Trials kept
- Channels interpolated
- Components or projection dimensions removed, and the variance they explained
- Residual artifact metrics, for example the RMS in the 10–30 ms window, high-frequency power after the pulse, and the baseline noise level

Test these quality metrics statistically between conditions. If the conditions differ systematically, say so and consider those metrics as covariates.

**Other identical steps**

- Filters: same filters, applied at the same point in the pipeline.
- Downsampling: same rate.
- Re-referencing: same reference.
- Time–frequency settings: same settings, and use the same strategy for handling the interpolated window, because it biases low-frequency power estimates.

### 6. Validate that the pipeline itself does not create a difference

- **Sensitivity analysis.** Rerun the main contrast with at least one alternative, defensible pipeline. Examples:
  - ICA-based (TESA-like) versus SSP-SIR/SOUND-based
  - Minimal cleaning restricted to later latencies

  Pipelines are known to produce noticeably different TEPs. Effects that survive across pipelines are much more credible.
- **Injection test (optional but persuasive).** Add a template of the active artifact, taken from residuals or from a phantom or head-model recording, to sham data. Run the cleaning and check that the cleaned "sham + artifact" data matches the original sham. This shows whether the pipeline is neutral with respect to the artifact difference.
- **Pre-stimulus check.** Confirm that there is no condition difference in the pre-stimulus baseline after cleaning. A difference there means filtering or interpolation has spread artifact into the baseline.

### 7. Statistics and interpretation

- Choose the time windows and regions of interest a priori, or use cluster-based permutation tests. In both cases, exclude the interpolated window and the early latencies that are uninterpretable in active.
- Interpret differences that coincide in time and space with residual muscle or decay artifact cautiously. Lateral or frontal targets and early latencies are the main concern.
- Interpret late differences (around N100/P200) only alongside the sensory-matching data. Those components are the most sensitive to auditory and somatosensory confounds.

## Minimal checklist

1. Pipeline frozen and blinded, using automated criteria
2. Same pulse-interpolation window in both conditions, set from active
3. Joint ICA on concatenated data, or the same SSP-SIR projector applied to both
4. Union of bad channels interpolated in both
5. Same rejection thresholds, then equal trial counts
6. Sensory responses not removed; matched by design and checked with ratings
7. Per-condition QC metrics reported and tested
8. Results robust across at least two pipelines, and the baseline shows no difference
