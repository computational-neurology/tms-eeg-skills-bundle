# Preprocessing active and sham TMS-EEG without biasing the comparison

## Short answer

Use **one pipeline, fixed in advance, applied identically to both conditions**. Set its parameters for the worse of the two artifact profiles, which is almost always active. Where a data-driven cleaning step is needed (ICA, SSP-SIR, SOUND), **fit it once on the pooled active and sham data from each participant**, or estimate it from active and apply the same operator to sham. Do not fit it separately per condition. Then show that the active–sham difference is not an artifact of the cleaning. To do that, report what was removed in each condition, check residual muscle, match trial counts, and run sensitivity analyses.

A different artifact profile is partly *the effect itself*. Real TMS produces a stronger click, scalp muscle twitch and decay artifacts that sham does not fully reproduce. Preprocessing cannot make the two conditions equivalent. Its job is to avoid adding a second, hidden condition difference on top of the real one.

## Assumptions

- Within-subject design: active and sham recorded in the same session, with the same cap, montage, amplifier settings and masking.
- Sham is a sham coil or tilted coil, possibly with scalp electrical stimulation. It produces a click and some scalp sensation but little or no TMS-evoked scalp muscle activity and a smaller pulse/decay artifact.
- Outcome is TEPs, GMFA and/or LMFP, compared between conditions or as an active-minus-sham contrast.
- Python/MNE-style processing. The same logic applies to EEGLAB/TESA.

## Why separate per-condition cleaning biases the result

| Per-condition choice | How it biases active vs sham |
|---|---|
| Shorter pulse-interpolation window for sham ("it has less artifact") | Sham keeps early samples that active loses. Early-window differences then reflect interpolation, not the brain. |
| Separate ICA per condition, components picked by eye | Different numbers and kinds of components are removed. ICA-based cleaning shrinks TEP amplitudes across all peaks, so removing more from active can shrink or even reverse the effect. |
| Separate SSP-SIR/SOUND projections | Different retained rank and different spatial filtering. Topographies and GMFA are then not comparable. Strong regularisation can also produce artifact-derived structure that looks like a TEP. |
| Same amplitude threshold, but active has more muscle | Active loses more trials, so its average has lower SNR. Residual noise raises GMFA, which inflates or masks differences. |
| Removing "auditory" or "somatosensory" ICA components | This removes exactly what sham is supposed to control for, and removes it unevenly. |

## Recommended workflow

Fix all parameters before unblinding to condition, ideally in a preregistered or locked analysis plan.

1. **Load and label.** Keep condition labels in the event codes, but process both conditions in a single per-participant data stream. Record metadata: sampling rate, pulse-timing source, sham type, masking, and sensory ratings.
2. **Verify pulse events in both conditions.** Sham pulses must be time-locked as precisely as active pulses. Check that the jitter is the same.
3. **Pulse-artifact window: one window for both conditions.** Define it from the *active* data, where decay/recharge lasts longest. Start from about −2 to 10–12 ms and widen it only if the active data require it. Apply that window to sham as well, even though sham looks clean earlier. Do not interpret any sample inside this window.
4. **Bad channels.** Use the same detection criteria across conditions. Mark them once per participant on the pooled data and exclude them from decomposition. Repair them after ICA/SOUND with the same method.
5. **Epoch and baseline.** Use the same epoch length and baseline window, for example about −500 to −50 ms, adjusted to your inter-pulse interval. Confirm that the baseline contains no residual decay or the tail of the previous pulse in either condition.
6. **Gross trial rejection before decomposition.** Use the same criteria for both conditions. Log rejections per condition.
7. **ICA for non-stimulus-locked artifacts only** (blinks, eye movements, background EMG):
   - Fit **one ICA per participant on concatenated active and sham epochs**. If the training copy is filtered or detrended to stabilise the decomposition, keep it separate from the analysis data.
   - Apply the same unmixing and the same excluded components to both conditions.
   - Choose components without seeing condition labels: blind the plots, or use automated suggestions with fixed criteria plus human verification.
   - **Do not** remove TMS-evoked muscle or clearly stimulus-locked components with ICA.
   - **Do not** remove auditory or somatosensory components. These are handled by the sham contrast.
8. **TMS-evoked muscle (mostly in active)**: use projection (SSP-SIR) or explicit window handling, not ICA.
   - Estimate the muscle subspace from the active data, where the artifact exists, or from the pooled data. Apply **the same projection operator, with the same number of components and the same retained rank, to both conditions**. This prevents the sham data from keeping dimensions that active has lost.
   - Starting values are only a starting point: `pc` around 2, artifact window around 5–50 ms checked against the real burst, manual artifact scaling.
   - If you use SOUND, use the same `lambda` and the same number of iterations in both conditions.
9. **Filtering, done late.** Use the same notch and low-pass filters (for example 80–100 Hz). Add a high-pass only if justified, and apply it to both conditions after pulse handling.
10. **Downsampling.** Same factor for both conditions, applied after pulse and timing QC.
11. **Final trial rejection.** Use the same thresholds. Then **equalise trial counts** between conditions within each participant, for example by random subsampling of the larger set (in MNE, `equalize_event_counts`). Alternatively, report the imbalance and show that results hold with equalised counts.
12. **Reference.** Use the same full-channel reference (average reference, or a justified CSD/Laplacian), applied at the same stage. Select LMFP ROI channels only after referencing, and use the same ROI for both conditions.
13. **Average, then compute TEP, GMFA and LMFP per condition**, and the active-minus-sham difference if you use subtraction.

Minimal sketch of the shared-decomposition idea in MNE (placeholders; check the API against your installed version):

```python
# per participant; 'active' and 'sham' are Epochs after identical steps 1-6
epochs_all = mne.concatenate_epochs([epochs_active, epochs_sham])
ica = mne.preprocessing.ICA(n_components=N_COMP, random_state=SEED)
ica.fit(epochs_ica_training_copy)          # pooled, bad channels excluded
ica.exclude = EXCLUDED_IDX                 # chosen blind to condition
epochs_all_clean = ica.apply(epochs_all.copy())
# same SSP-SIR/SOUND operator, same filter, same reference applied to epochs_all_clean
epochs_all_clean.equalize_event_counts(["active", "sham"])
```

## QC that shows the cleaning did not create the effect

Report each of these **per condition**:

- **What was removed.** Number of components or projections (the same in both conditions by design), the variance removed from each condition's data, and retained rank after each rank-reducing step. Show the time course, topography and spectrum of every removed component, not just the count.
- **Before/after overlays.** For each condition, plot the pre- and post-cleaning butterfly, GMFA and topographies over 0–100 ms. If cleaning changes active much more than sham inside your analysis window, that window is at risk.
- **Trial counts.** Retained trials per condition and per participant, with rejection reasons.
- **Residual muscle in active.** Classify participants by whether muscle activity is visible in the *uncleaned* active 5–15 ms data. Compare the cleaned active TEPs and the active–sham differences between the muscle and no-muscle subgroups. If they diverge, the early-window contrast is not trustworthy. Residual muscle after ICA is common with frontal and lateral targets. In one large dataset it remained in about 62% of participants after prefrontal stimulation and about 35% after premotor.
- **Baseline check.** Show that the baseline window is clean in both conditions.
- **Sensitivity analysis.** Re-run the active–sham contrast while varying the key choices: pulse window (for example −2 to 10 vs −2 to 15 ms), SSP-SIR `pc` (1/2/3), number of ICA components, and a minimal pipeline with no ICA. A robust effect keeps its sign and approximate latency. An effect that appears only under one setting is likely to be a preprocessing effect.

## Interpretation caveats

- **Sham controls sensory input only partly.** Even when participants cannot tell active from sham, N45, N100 and P180 can still be larger for active TMS at sub-threshold intensity than for realistic sham (Gordon et al. 2018). Masking and ICA do not remove sensory contributions completely.
- **Sham subtraction is supported, within limits.** With well-matched sham (PEP-saturating or individually PEP-matched), no significant interaction between somatosensory input and the TEP was found within about 110 ms for M1 and SMA (Gordon et al. 2026). This supports subtracting a *matched* sham. It does not cover unmatched sham, later windows or other targets, and a sham-subtracted TEP is not automatically pure cortical activity.
- **Latency matters.**
  - Peripherally evoked potentials overlap TEPs mainly from about 60 ms onward (broad frontocentral N100/P180–200). Late active–sham differences can therefore reflect a louder click or a scalp twitch.
  - Early windows are more cortically specific, but in active they are more exposed to residual muscle and decay.
  - Neither window is "clean" by default.
- **Collect sensory ratings for both conditions**, rated separately: loudness, twitch, discomfort and pain. Click loudness has the strongest influence on late TEP amplitude. Pain ratings are not a good proxy for sensory contamination. Use the ratings as covariates or matching checks.
- **Do not describe active–sham TEP or GMFA differences as a pure measure of cortical excitability.** They are scalp-level responses shaped by cortical, sensory, muscle and preprocessing factors.

## Methods-section checklist

- Same pipeline and parameters for both conditions, fixed in advance.
- Pulse window, baseline, filters, reference and downsampling stated once and applied to both.
- ICA fitted on pooled data, rejection criteria stated, components chosen blind to condition, removed components shown.
- SSP-SIR/SOUND parameters and retained rank, identical across conditions.
- Retained trials per condition, with the equalisation method.
- Residual-muscle subgroup check and sensitivity analyses.
- Sham type, masking procedure and per-condition sensory ratings.
